# 本站账号管理

统一身份认证入口为 `https://account.yaoxi.wiki`。登录凭据中的 `picture` 字段用于导航栏、用户面板、评论头像和后台账号列表；只接受该域名下的头像路径，加载失败回退到姓名首字。用户下次登录或刷新博客时同步其头像资料。

## 管理入口

管理员登录 `/admin/`，打开「本站账号」。列表仅包含登录访问过博客或在本站发表过内容的账号，不拉取认证中心的全站账号库。

支持用户名、昵称、账号 ID 搜索；按认证、禁言、停用、强制审核筛选；分页与勾选批量操作。详细设置提供：

- 授予或取消本站认证，填写认证说明。本站认证与 SSO 登录身份独立。
- 解除禁言、禁言一小时/一天/七天、永久禁言或自定义截止时间。
- 单独允许或禁止评论、弹幕；强制人工审核。
- 启用或停用本站互动权限，添加仅管理员可见的备注。
- 查看最近 100 条操作记录，包含操作者、时间和设置前后值。

配置按版本更新；后台发现并发改动时要求刷新，避免覆盖别人的操作。不能通过本站管理授予认证中心管理员角色，也不能禁言或停用认证中心管理员。操作仅影响本站互动，不改变认证中心的密码、角色、会话或其他站点权限。

## 提交规则

评论、回复、弹幕均需登录，以防退出登录后绕过账号禁言。旧弹幕提交接口遵循相同规则。每次投稿重新读取本站账号策略，禁言、停用或关闭相应权限时拒绝请求；已过期的限时禁言自动失效。作者仍可撤回自己的旧内容。

腾讯云返回 `Pass` 时默认自动通过；账号开启「强制人工审核」后，即使 `Pass` 也待审。`Review`、异常和未启用检测时待审，`Block` 拒绝。认证标记不能绕过文本检测。

## 接口与存储

- `POST /api/account/sync`：使用已验签的 SSO 身份同步本人资料，不信任请求体中的昵称、头像或权限。
- `GET /api/admin/accounts?q=&filter=&after=`：管理员列表，每页 50 条。
- `POST /api/admin/accounts/update`：`sub`、当前 `version`、白名单 `patch` 字段；更新与审计原子提交。
- `GET /api/admin/accounts/events?sub=`：管理员操作记录。

`site_accounts`、`site_account_events` 位于现有 D1/SQLite 数据库。首次请求执行幂等、增量的结构初始化，不改写已有评论或账号规则。旧评论身份仅在管理员读取列表时补入；之后的登录资料同步只更新基本资料，不清除禁言与权限。历史评论读取时关联当前头像和本站认证，公开响应不暴露管理备注和操作记录。

部署沿用远端 CI。`tests/site-accounts.test.mjs` 使用内存 SQLite 验证真实 SQL、身份边界、权限生效、过期禁言、版本冲突和审计事务，不执行本地构建。
