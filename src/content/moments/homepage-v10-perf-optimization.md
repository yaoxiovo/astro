【主页 v10 极致性能改造完成】

瑶曦主页（yaoxi-ovo）已完成极致性能重构，在保留拟态液态玻璃 UI 的前提下，首屏资源大幅瘦身：

📊 优化成果
· 图片：WebP → AVIF 全覆盖，320KB → 129KB（-60%）
· 字体：Google Fonts 全量 → 本地子集化，88.6KB 自托管（-78%，零第三方请求）
· CSS：独立请求 → 内联进 HTML，首屏零样式请求
· 图标：remixicon 全量 144KB → 仅保留 16 个图标字形，1.9KB（-99%）
· 首屏关键资源：gzip 后约 70KB

🛠 技术要点
· 引入 esbuild 构建流水线（npm run build → dist/），产物零额外开销
· 中端机降级策略：小屏设备自动关闭 backdrop-filter 模糊，玻璃质感用高不透明度补偿
· 修复 PWA Service Worker 激活失败、滚动闪频、主题切换闪变等历史问题

📦 构建产物已同步，部署 dist/ 即可生效。
